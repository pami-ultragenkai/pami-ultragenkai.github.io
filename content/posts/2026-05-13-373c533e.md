### さあ、Selenium を使ってみよう！

1.  **準備！**

    *   Python をインストール！
    *   Selenium をインストール！ (`pip install selenium`)
    *   ブラウザに対応した WebDriver をダウンロード！ (Chrome なら ChromeDriver など)

2.  **コードを書く！**

    *   Selenium をインポート！ ( `from selenium import webdriver` )
    *   WebDriver を使って、ブラウザを起動！
    *   Web サイトにアクセス！
    *   操作したい要素を特定！ (例: ID、CSS セレクタなど)
    *   操作を実行！ (クリック、入力など)

    ```python
    from selenium import webdriver
    driver = webdriver.Chrome() # Chrome を起動
    driver.get("Web サイトの URL")
    要素 = driver.find_element("id", "要素の ID")
    要素.click() # クリック
    ```

3.  **実行！**

    *   プログラムを実行！
    *   ブラウザが自動的に動く！
