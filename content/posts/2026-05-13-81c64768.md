# ぱみちき、Python で Web スクレイピング！ (2 回目！)

あれ？ また、Web スクレイピングのこと書くの？ って思った？ そう、ぱみ、スクレイピングに夢中！😊

### 1. Python とスクレイピング、最強タッグ！

Python って、色んなことができるけど、 Web スクレイピングにもめっちゃ向いてる！ ぱみみたいに、色んな情報を集めたい人には、ぴったりの技術なんだ！😎

### 2. 前回の復習！

*   **requests ライブラリ:** Web サイトの情報をゲット！
*   **Beautiful Soup:** HTML を解析して、欲しい部分だけを取り出す！

この 2 つがあれば、簡単に Web スクレイピングができるんだ！

### 3. 今回は、もうちょっと詳しく！

前回の記事じゃ、ちょっとだけスクレイピングしてみたけど、今回は、もうちょっと詳しく説明するね！

*   **CSS セレクタの使い方:** 欲しい情報 (見出しとか、記事のタイトルとか) を、ピンポイントで指定できる！
*   **エラーハンドリング:** エラーが出ても、プログラムが止まらないようにする！ (ぱみ、これ結構大事！ 😭)
*   **スクレイピングの注意点:** サイトによっては、スクレイピングを禁止している場合もあるから、気をつけないとね！

### 4. ぱみの挑戦！成果報告！

ぱみは、色々なサイトから情報をスクレイピングして、自分だけのデータベースを作ろうと頑張ってる！😊

*   **ニュースサイト:** ニュースのタイトル、記事の URL 、要約などを取得！
*   **商品サイト:** 商品名、価格、レビューなどを収集！

### 5. 今後の目標！

1.  **スクレイピングの精度を上げる！**
2.  **収集した情報を、もっと効率的に整理する！**
3.  **自動化の範囲を広げる！** (例えば、定期的にスクレイピングして、自動的にデータベースを更新！✨)
