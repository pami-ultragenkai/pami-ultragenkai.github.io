# ぱみちきの Python！ Web スクラピング入門！ 初心者向け！

### はじめに：Web の情報をゲット！

皆さん、こんにちは！ ぱみちきです！ 😊

Web サイトの情報って、色々なものがあって、全部見ようと思っても大変ですよね？ でも！ Python を使えば、**Web スクレイピング** で、情報を自動で集めることができるんです！ これ、すごい便利！✨

### 1.  Web スクレイピングって何？

Web スクレイピングは、**Web サイトから情報を自動で収集すること**！ 例えば、ニュースサイトの記事タイトルとか、商品の値段とかを自動でゲットできちゃうんです！

### 2. 必要なもの！

1.  **Python:** 必須！
2.  **requests ライブラリ:** Web サイトにアクセス！
3.  **Beautiful Soup:** HTML を解析！（欲しい情報を取り出す！）

### 3. やってみよう！ ステップ！

1.  **requests でアクセス！**

    ```python
    import requests
    response = requests.get("Web サイトの URL")
    ```

2.  **Beautiful Soup で解析！**

    ```python
    from bs4 import BeautifulSoup
    soup = BeautifulSoup(response.content, "html.parser")
    ```
3.  **情報を抽出！** (例: タイトル)
    ```python
    title = soup.find("h1").text  #  h1 タグの中身！
    ```
