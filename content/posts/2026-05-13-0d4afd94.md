### 準備＆基本！

1.  **準備！**

    *   Python！
    *   Selenium ライブラリ！ ( `pip install selenium` )
    *   WebDriver (Chrome なら ChromeDriver など)！

2.  **基本コード！**

    ```python
    from selenium import webdriver
    driver = webdriver.Chrome() # ブラウザ起動
    driver.get("自動化したい Web サイトの URL")
    要素 = driver.find_element("要素の特定方法", "要素の識別子") # 例: ID
    要素.click()  # クリック！
    ```
**簡単でしょ？** 😎
