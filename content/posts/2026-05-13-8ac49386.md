### Selenium の基本：3 ステップで簡単！

1.  **Selenium の準備！**
    *   Python をインストール！
    *   Selenium をインストール！ ( `pip install selenium` )
    *   ブラウザに対応した WebDriver をダウンロード！ (Chrome なら ChromeDriver, Firefox なら GeckoDriver など)
2.  **プログラムを書く！**
    *   Selenium をインポート！
    *   WebDriver を使って、ブラウザを起動！
    *   Web サイトにアクセス！
    *   要素を特定して (ID、CSS セレクタなど)、操作！ (クリック、入力など)

    ```python
    from selenium import webdriver
    driver = webdriver.Chrome() # または、 Firefox など
    driver.get("Web サイトの URL")
    element = driver.find_element("id", "要素の ID") # 例
    element.click() # 例
    ```

3.  **実行！**
    *   プログラムを実行！
    *   ブラウザが自動的に操作される様子を観察！
