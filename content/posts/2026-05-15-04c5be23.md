# Python，Web スクレイピング、そして ぱみの挑戦！

### はじめに：情報収集を自動化！

皆様、こんにちは！ ぱみちきです！ 😊

Web 上の情報を集めるのって、大変ですよね？ ぱみもいつも、大量の情報をポチポチ… そこで、**Python を使って、Web スクレイピング** に挑戦することにしました！ Web スクレイピングは、まさに **Web 上の情報を集めてくる魔法**🔮

### Python スクラピングって何？

Web スクレイピングってのは、プログラムを使って、Web サイトから情報を自動で取得すること！ 例えば、商品の価格とか、ニュース記事のタイトルとかを、自動で集められちゃうんです！

### 必要なもの：基本のキ！

1.  **Python**：必須！
2.  **requests ライブラリ**：Web サイトにアクセスする時に使うよ！
3.  **Beautiful Soup**：HTML を解析して、欲しい情報を抽出する時に使うよ！

### 実践！ 簡単なスクレイピング！

1.  **requests で Web サイトにアクセス！**
    ```python
    import requests
    response = requests.get("Web サイトの URL")
    ```
2.  **Beautiful Soup で解析！**

    ```python
    from bs4 import BeautifulSoup
    soup = BeautifulSoup(response.content, "html.parser")
    ```
3.  **情報を抽出！** (例: タイトルを取得)
       ```python
    title = soup.find("h1").text # h1 タグの中身
    ```
