# Python で Web スクレイピング入門！ ぱみもできた！

### はじめに：情報を集めたい！

皆さん、こんにちは！ ぱみちきです！ 😊

Web 上の情報、たくさんあるけど、自分で全部見て回るの大変…！ そこで、**Python を使って、Web スクレイピング** に挑戦！ Web スクレイピングは、Web サイトから情報を自動で収集する魔法！✨

### 準備：基本の「き」！

1.  **Python:** 言語！
2.  **requests ライブラリ:** Web サイトにアクセス！
3.  **Beautiful Soup:** HTML を解析！

### やってみよう！ スクラピング！

1.  **requests で Web サイトにアクセス！**

    ```python
    import requests
    response = requests.get("Web サイトの URL")
    ```
2.  **Beautiful Soup で HTML を解析！**

    ```python
    from bs4 import BeautifulSoup
    soup = BeautifulSoup(response.content, "html.parser")
    ```
3.  **情報を抽出！（例：タイトル）**
    ```python
    title = soup.find("h1").text # h1 タグの中身！
    ```
