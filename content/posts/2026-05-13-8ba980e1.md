# ぱみ流 Selenium！Web 自動化！

### はじめに：退屈な作業、さようなら！👋

エンジニアの皆さん、こんにちは！ ぱみちきです！ 😊

日々の業務で、Web サイトのデータ入力とか、同じ操作を何度も繰り返すことって、ありますよね？ めっちゃ時間の無駄だし、つまらない…！ そこで！ Selenium を使って、**Web ブラウザの操作を自動化する**ことに挑戦しました！ これで、**退屈な作業から解放され、もっとクリエイティブな仕事に集中できる** んです！✨

### Selenium は、どんな魔法使い？

1.  **Web サイト操作を自動化！**
    *   ログイン、クリック、テキスト入力… ブラウザでできることは何でも！
    *   面倒な作業を、プログラムが代わりにやってくれる！
2.  **多機能！**
    *   特定の要素を簡単に選択できる！
    *   動的な Web サイトにも対応！

### 準備するもの

1.  **Python:** 言語！
2.  **Selenium ライブラリ:** インストール！ (`pip install selenium`)
3.  **WebDriver:** ブラウザに対応したドライバー！ (例: Chrome なら ChromeDriver)

### まずは、ログインを自動化！

1.  **ドライバーの設定:**
    ```python
    from selenium import webdriver
    driver = webdriver.Chrome() # 例：Chrome を使用
    ```
2.  **Web サイトにアクセス！**
    ```python
    driver.get("ログインしたい Web サイトの URL")
    ```
3.  **要素を特定！**
    *   ユーザー名、パスワードの入力欄、ログインボタンなど、必要な要素を特定するんだ！
    ```python
    username = driver.find_element("id", "username")
    password = driver.find_element("id", "password")
    login_button = driver.find_element("id", "login")
    ```
4.  **入力＆クリック！**
    ```python
    username.send_keys("あなたのユーザー名")
    password.send_keys("あなたのパスワード")
    login_button.click()
    ```
