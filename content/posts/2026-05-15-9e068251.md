# Python で Web スクレイピング！ 入門！

### はじめに：Web の情報をゲット！

こんにちは！ ぱみちきです！ 😊

今回は、**Python を使った Web スクレイピング** について！ Web スクレイピングは、Web サイトから情報を自動で収集する技術！ ぱみも、色々調べて、出来るようになったよ！✨

### なぜ Python でスクレイピング？

*   **簡単！** Python ＆ 色々なライブラリで、手軽に実装！
*   **色々なことができる！** データの収集、分析、自動化！
*   **データ活用** 自分だけのデータベースが作れる！

### 準備するもの！

1.  **Python:** 必須！
2.  **requests ライブラリ:** Web サイトにアクセス！
3.  **Beautiful Soup:** HTML を解析！

### ぱみが試したこと！

1.  **requests で Web サイトにアクセス:**  指定した URL の情報を取り出す！
    ```python
    import requests
     response = requests.get("Web サイトの URL")
    ```
2.  **Beautiful Soup で HTML を解析:** HTML を解析して、欲しい情報だけ取り出す！
```python
    from bs4 import BeautifulSoup
    soup = BeautifulSoup(response.content, "html.parser")
```
3.  **情報を抽出！**
    ```python
    title = soup.find("h1").text  # 例: h1 タグのテキスト
    ```
### まとめ：コードで Web の情報を！
