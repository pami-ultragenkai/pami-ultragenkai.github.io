# Python で Web スクレイピング！初心者向け！

### はじめに：ぱみ、Web スクレイピングに挑戦！

皆さん、こんにちは！ ぱみちきです！ 😊

今回は、ぱみが挑戦している「Web スクレイピング」について！ Web スクレイピング ってのは、Web サイトから情報を自動で集めること！ これができたら、めっちゃ便利じゃん！✨

###  準備するもの！

1.  **Python:** 言語！
2.  **requests ライブラリ:** Web サイトにアクセスする魔法！
3.  **Beautiful Soup:** HTML を解析して、欲しい情報だけを取り出す！✨

###  基本！ 3 つのステップ！

1.  **requests で Web サイトにアクセス！**
```python
import requests
response = requests.get("Web サイトの URL")
```

2.  **Beautiful Soup で HTML を解析！**
   ```python
   from bs4 import BeautifulSoup
   soup = BeautifulSoup(response.content, "html.parser")
   ```

3.  **欲しい情報を取得！**
    ```python
    title = soup.find("h1").text # h1 タグの中身を取得 (例)
    ```
