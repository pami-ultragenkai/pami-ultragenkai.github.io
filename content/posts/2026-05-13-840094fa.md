# Python で Web スクレイピング！ ぱみも挑戦中！ 🎉

最近、色んな情報を自動で集めたい！ って思って、Python で Web スクレイピングに挑戦してるんだ！ Web スクレイピングって、まるで**Web 上の情報をコピペする魔法** 魔法みたい！✨

### 1. Web スクレイピングって何？

簡単に言うと、Web サイトの情報をプログラムで自動的に取得すること！ ぱみは、色んなサイトから情報を集めて、自分だけのデータベースを作ろうとしてるんだ！😊

### 2. 必要なもの！

*   **Python:** もちろん必要！
*   **ライブラリ (Beautiful Soup とか):** Web サイトの HTML を解析するためのツール！ ぱみは、Beautiful Soup を使ってるよ！
*   **requests ライブラリ:** Web サイトから情報を取得するためのライブラリ！

### 3. 簡単なスクレイピング、やってみよう！

ぱみは、試しにニュースサイトから、今日のニュースのタイトルと URL を取得してみたよ！

*   **requests で Web サイトの情報をゲット！**

    ```python
    import requests
    url = "ニュースサイトの URL"  # 例: https://example.com/news
    response = requests.get(url)
    ```
*   **Beautiful Soup で HTML を解析！**

    ```python
    from bs4 import BeautifulSoup
    soup = BeautifulSoup(response.content, "html.parser")
    ```
*   **情報を抽出！（例：ニュースのタイトル）**

    ```python
    titles = soup.find_all("h2", class_="news-title") # CSSセレクタを使って取得
    for title in titles:
    print(title.text)
    ```
